数码电商平台 · 后端接口文档（REST API）

Spring Boot + JWT · 前后端分离 · 含大模型导购 SSE 流式接口 · 与数据库 digital_mall（24张表）一一对应

约定
全局约定 认证模块
用户端
用户资料/地址/收藏 商品检索 购物车 订单 支付 评价 售后 大模型导购
商家端
入驻/店铺/商品/发货
管理端
用户/审核/商品/统计 错误码

全局约定

Base URL：http://localhost:8080/api（后端统一前缀 /api）

数据格式：JSON（UTF-8），请求头 Content-Type: application/json

认证方式：登录接口返回 token（JWT），后续请求携带 Authorization: Bearer {token}；无/过期 Token 返回 401，越权访问返回 403

角色权限标注：公开 无需登录 · 用户 普通用户 · 商家 · 管理员

分页参数：pageNum（默认1）、pageSize（默认10），返回 PageResult { total, pageNum, pageSize, list }

统一响应结构 Result<T>

// 成功
{ "code": 200, "message": "success", "data": { } }
// 失败
{ "code": 409, "message": "库存不足", "data": null }

一、认证模块 AuthController

POST/auth/register公开用户注册（验证码可选）
请求参数（JSON）
参数类型必填说明
usernamestring是登录账号，唯一
passwordstring是密码，BCrypt 加密存储，6-20位
nicknamestring否昵称
phonestring否手机号（找回密码用）
emailstring否邮箱
codestring否短信验证码（与 /auth/sms-code 联动）
返回示例
{ "code": 200, "message": "success", "data": {
  "token": "eyJhbGciOiJIUzI1NiJ9...",
  "user": { "id": 1, "username": "zhangsan", "nickname": "张三", "avatar": null, "role": 0 }
} }
POST/auth/login公开登录（账号密码）
请求参数

九、大模型智能导购 ChatController（核心特色）

POST/chat/send用户发送消息，SSE 流式返回（意图→召回→回答）
请求参数（JSON）
参数类型必填说明
sessionIdlong是会话ID（首次对话先建会话）
contentstring是用户自然语言输入，如"3000以内拍照好的手机"
响应：text/event-stream（SSE，Content-Type: text/event-stream）
前端使用 EventSource / fetch 流式读取。完整事件流：
event: intent
data: {"intent":"find_product","slots":{"category":"手机","budget":3000,"keyword":"拍照"}}

event: products
data: [{"id":8,"productName":"小米 15","price":2999.00,"similarity":0.93,"sales":5210},
       {"id":12,"productName":"荣耀 Magic7","price":3199.00,"similarity":0.89,"sales":2310}]

event: answer
data: {"content":"根据您的预算和拍照需求，推荐：…"}
data: {"content":"小米 15 搭载徕卡影像…"}      // 多个 data 增量拼接

event: done
data: {"sessionId":1,"messageId":88,"intent":"find_product","tokenCount":860}
后端处理链路（答辩重点）
① 意图识别：调用 LLM 对输入做意图分类（找商品/参数对比/选购建议/闲聊），抽取槽位（品类/预算/关键词）→ ② 向量召回：按槽位组合 query，调 Embedding 接口生成向量，在 Redis 中余弦相似度检索 TopN 商品 → ③ 组装 Prompt：注入召回商品的结构化信息（名称/价格/参数/评价分）+ 系统提示词（只推荐库内商品、输出对比表格、控制幻觉）→ ④ 调 LLM 流式生成回答（SSE 逐字返回）→ ⑤ 落库：用户消息与助手消息写入 chat_message（intent、product_ids、token_count）。
前端事件解析建议
// fetch 流式读取示例（简化）
const resp = await fetch('/api/chat/send', { method: 'POST', headers: { 'Authorization': 'Bearer ' + token,
  'Content-Type': 'application/json' }, body: JSON.stringify({ sessionId, content }) });
const reader = resp.body.getReader(); // 按 event/data 分帧解析
POST/chat/session用户创建导购会话
参数类型必填说明
titlestring否会话标题（可空，后端可自动摘要）
GET/chat/session/page用户历史会话列表（时间倒序）
DELETE/chat/session/{id}用户删除会话及其消息
GET/chat/message/page?sessionId=用户会话历史消息（支撑多轮上下文与前端回显）
返回 [{ role: 0|1, content, productIds: [1,2], intent, createdTime }]。
POST/chat/knowledge/sync管理员商品知识库向量化（初始化/全量重建）
请求参数
参数类型必填说明
fullboolean否true=全量重建；false/空=增量（仅未向量化的商品）
业务规则
遍历上架商品，拼接文本（名称+卖点+参数+标签）→ 调 Embedding 接口 → 写入 Redis product:embedding:{productId}。商品上下架时同步删除/添加向量。
GET/chat/hot-questions公开导购快捷提问（前端聊天框快捷入口）
返回预置问题数组：如 ["5000以内的旗舰手机推荐", "iPhone 和华为 怎么选", "适合学生党的笔记本"]。

十二、错误码约定

code含义典型场景
200成功—
400参数错误缺少必填参数、格式错误
401未认证 / Token 失效未登录、Token 过期或被禁用
403无权限角色越权访问（商家调管理员接口等）
404资源不存在商品/订单/地址不存在
409业务冲突库存不足、重复评价、重复入驻申请、订单状态不允许操作
500服务器异常未知异常（全局异常处理器兜底）
后端实现建议：全局异常处理器（@RestControllerAdvice）+ 自定义 BusinessException(code, message)；Spring Security 或自定义拦截器做 JWT 解析与 @RequireRole 注解鉴权。
