十二、错误码约定
code
含义
典型场景
200
成功
—
400
参数错误
缺少必填参数、格式错误
401
未认证 / Token 失效
未登录、Token 过期或被禁用
403
无权限
角色越权访问（商家调管理员接口等）
404
资源不存在

===== 商品/订单/地址不存在 =====
409
业务冲突
库存不足、重复评价、重复入驻申请、订单状态不允许操作
500
服务器异常
未知异常（全局异常处理器兜底）
后端实现建议：全局异常处理器（@RestControllerAdvice）+ 自定义 BusinessException(code, message)；Spring Security 或自定义拦截器做 JWT 解析与 @RequireRole 注解鉴权。
